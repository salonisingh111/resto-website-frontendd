# 🍽️ Savora – Luxury Indian Restaurant Website

Savora is a modern and responsive restaurant website designed to provide an elegant online dining experience. The project showcases authentic Indian cuisine through a visually appealing interface, allowing users to explore the menu, reserve tables, browse featured dishes, and manage their food cart.

## ✨ Features

* 🏠 Elegant landing page with a responsive navigation bar
* 🍛 Interactive food menu with multiple categories
* 📅 Table reservation page
* 🛒 Shopping cart with item count and total price
* ⭐ Featured signature dishes section
* 📖 About section highlighting the restaurant's story
* 💬 Customer testimonials
* 📱 Fully responsive design for desktop and mobile devices
* 🎠 Hero image carousel
* 🎨 Modern UI with smooth animations

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* GSAP (GreenSock Animation Platform)
* Google Fonts
* Responsive Web Design

## 🚀 Getting Started

1. Clone this repository:

```bash
git clone https://github.com/your-username/savora.git
```

2. Open the project folder.

3. Launch `index.html` in your preferred web browser.

4. Explore the website by navigating through the menu, reservation, about, contact, and cart pages.
